# Hệ Thống Quản Lý & Phân Tích Công Nợ Toàn Diện (AR + AP Automation & Analytics)

Dự án tự động hóa nghiệp vụ và phân tích công nợ Phải thu (Accounts Receivable - AR) & Phải trả (Accounts Payable - AP) sử dụng SQL Server, Excel VBA, Power Automate và Power BI.

## Cấu trúc thư mục
* `/sql/`: Lưu trữ các file scripts SQL (Database creation, Procedures, Queries, Views)
* `/vba/`: Lưu trữ mã nguồn VBA xuất từ Excel
* `/power-bi/`: Lưu trữ các file báo cáo Power BI (.pbix)
* `/docs/`: Sơ đồ ERD và tài liệu hướng dẫn nghiệp vụ
